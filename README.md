# FORM OPTICS · 眼镜定制工坊

一个赛博朋克风格的实时 3D 眼镜定制原型。用户选择镜框、颜色、镜腿 Logo 和数量，确认产品图后可以用模拟支付体验机器人制作、装盒和回仓充电。

## 当前功能

- 三种镜框轮廓、五种颜色，支持上传 PNG、JPG 或 WebP 作为镜腿 Logo。
- 在棚拍风格的写实渲染图和可拖动的实时 3D 预览之间切换，支持下载 PNG。
- 模拟支付后，小票的长度、打印耗时和机器人表情随订单数量变化。
- 每副眼镜从机台底部的滑轨抽屉取出方形板材，依次完成切框、制作两根镜腿、组装、喷色、可选印标、质检、装盒和传送带出料。
- 传送带每送出一盒，制作进度加一。6 副及以上订单默认原速展示第一副，后续逐副以 4 倍速播放，可切回原速。
- 最后一盒出料后机器人回仓。仓门关闭后从 10 秒开始倒数，门外显示充电状态。收到新订单可提前开门出仓。

订单和图片在当前浏览器页面内处理。本项目面向演示，使用模拟支付，工坊画面展示制作过程的模拟动画。

## 技术栈

- Vite 提供本地开发和静态构建。
- Three.js 渲染工坊、眼镜模型和写实商品图。
- GSAP 编排接单、制作、装盒和充电动画。
- Node.js 测试运行器和 Playwright 验证订单逻辑与浏览器流程。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。浏览器流程测试使用已安装的 Chrome。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。运行浏览器测试时，保持开发服务器运行。

```bash
npm test
npm run test:browser
npm run build
```

静态构建输出位于 `dist/`。

## 代码结构

| 路径 | 内容 |
| --- | --- |
| `src/app.js` | 定制表单、预览切换、模拟支付和制作状态 |
| `src/order.js` | 镜框、颜色、订单校验与制作阶段 |
| `src/stage.js`、`src/workshop.js` | 3D 工坊、机器人、充电仓和场景控制 |
| `src/choreography.js` | 工坊制作与装盒动画编排 |
| `src/glasses.js`、`src/photo.js` | 眼镜模型、镜腿贴图和商品图渲染 |
| `tests/`、`scripts/browser-smoke.mjs` | 订单逻辑和浏览器流程测试 |
